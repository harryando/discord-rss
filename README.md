Auto forward RSS Blog artikel ke Discord Channel
 ---------------------------------------------------------------
 Fitur utama:
 - Forward postingan yang sudah difilter berdasarkan keyword dari blog ke discord channel

 ---------------------------------------------------------------
 Cara Menjalankan di lokal: 
  - pip3 install -r requirements.txt
  - python3 bot.py

 Cara menjalankan di Ubuntu:
  - python3 -m venv .venv
  - source .venv/bin/activate
  - pip3 install discord feedparser
  - python3 bot.py
